# 🏔️ Karakoram Explorer

Welcome to **Karakoram Explorer**, a premium web experience showcasing the breathtaking beauty of Northern Pakistan. This project is a modern, responsive landing page dedicated to the majestic landscapes of Gilgit-Baltistan.

---
#testing CI/CD
## ✨ Features
* **Premium UI/UX:** A clean, modern design with a focus on high-definition mountain aesthetics.
* **Interactive Cards:** Beautifully designed destination cards for Hunza, Skardu, and Attabad Lake.
* **Animations:** Smooth hover effects on images and animated call-to-action buttons.
* **Fully Responsive:** Optimized for viewing on desktops, tablets, and mobile devices.
* **Dockerized:** Containerized using Docker for easy deployment and consistent performance.

---

## 🛠️ Tech Stack
* **HTML5 & CSS3:** For structure and advanced styling.
* **Google Fonts:** Utilizing 'Poppins' for a professional typography look.
* **Docker:** For seamless environment setup.

---

## 🚀 How to Run Locally

To run this project on your local machine using Docker, follow these steps:

docker build -t karakoram-app .

docker run -d -p 8080:80 --name umme-sahar-site karakoram-app
